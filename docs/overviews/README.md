# Overviews

Un **overview** es un documento vivo, en español, que se lee **sin saber programar** y a la vez enlaza los ficheros reales
de un área (pantallas, flujo, reglas). Uno por área **cuando el área exista**; ninguno en abstracto.

Se actualiza en el **cierre** de la tarea que cambia esa área (manual de operación §2, «La etapa de cierre»), en el mismo
PR.

La plantilla todavía no tiene áreas de producto: el primer overview nace con la primera feature de una app derivada.
