## Parte 2 · Plan

### Verificación previa

Contra el commit: `328c41e`. No existe `.claude/` en el repo. En el entorno: `python3` y `jq` [medido]; los hooks usan
solo `python3` y cada uno comprueba que exista. El candado (`candado.sh estado`) existe desde la Fase 6.5.

### Solución

- `guard-protected-files.sh` (PreToolUse, `Edit|Write|MultiEdit`): JSON en stdout con exit 0; deny para secretos y
  config nativa; ask para `settings.gradle.kts`, `build.gradle.kts` raíz y el catálogo; **falla cerrado** (sin `python3`
  o sin `file_path` → ask).
- Stop, **fallan abiertos**: `stop-run-jvm-tests.sh` (distingue tests rojos de build roto), `stop-verificadores.sh` (los
  verificadores de la puerta sin Gradle), `stop-ui-audit-reminder.sh` (árbol sucio o último commit con UI). Todos:
  `stop_hook_active` → 0; candado VIVO → 0; candado huérfano → corren y no lo borran.
- `hooks_test.sh` en la puerta (sin Gradle); `--completo` a mano. Regla añadida a `CLAUDE.md` §4.
