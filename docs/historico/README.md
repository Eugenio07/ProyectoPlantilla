# Histórico

Aquí van los planes ya fusionados (`planes/`) y los informes de auditoría (`auditorias/`).

**Lo que entra aquí no se reescribe.** Solo se añade, junto a lo que otra rama corrigió, una línea:

```
Superado el AAAA-MM-DD → <puntero>
```

Un plan pasa a `planes/` **después** de fusionar, como primer commit de la rama de la tarea siguiente, extrayendo
antes lo que siga vivo y reapuntando a quien lo cite (manual de operación §2). Lo que vive de una auditoría es la
cola (`docs/deuda-tecnica.md`), no su informe.
