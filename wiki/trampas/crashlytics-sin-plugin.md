# Android crashea al arrancar: «The Crashlytics build ID is missing».

- **Síntoma:** Android crashea al arrancar: «The Crashlytics build ID is missing».
- **Causa:** Firebase inicializado (con `google-services.json`) y sin el plugin de Crashlytics.
- **Regla:** CLAUDE.md §8 «Aplica los plugins de google-services y Crashlytics juntos».
